# 600 family insan kontrolü

Her kişinin klasöründe tarayıcıda açılacak HTML, orijinal formatta 150 kayıtlık JSONL
ve görev/metadata içeren JSON paketi vardır. Göndermek için HTML + JSONL yeterlidir.

| Kişi | Veri | Öncelikli uyarılı |
|---|---|---:|
| Burak | Claude 1–150 | 63 |
| Kuzey | Claude 151–300 | 73 |
| Emir | Codex 1–150 | 74 |
| Murat | Codex 151–300 | 86 |

Bütün örnekler incelenir; uyarılılar önce gösterilir. Kararlar tarayıcıda yerel saklanır.
Bitince **Kararları JSON olarak indir** düğmesiyle sonucu indirin ve koordinatöre gönderin.
HTML dosyasının yerini değiştirince eski tarayıcı notları görünmeyebilir; önce indirin.
Gold görünür olduğu için bu etiketli düzeltme turudur, kör agreement değerlendirmesi değildir.
Orijinal benchmark kayıtları bu sayfalardan değiştirilmez.
